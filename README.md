### 🚀 About Me

### Software Tester | Manual QA | Test Automation  
My Name is Neama Mohamed, I'm a Software Tester with hands-on experience in testing web applications, validating APIs, designing test cases, and identifying defects to improve software quality and user experience.  
My experience includes manual testing, functional and regression testing, API testing, UI/UX validation, responsive testing, and performance testing. I also have practical skills in test automation using Playwright and TypeScript and I'm continuously enhancing my automation expertise and applying modern testing practices.  
## 🧪 Testing Skills  
### 🔍 Manual Testing  
- Functional Testing, Regression Testing,  Integration Testing, End-to-End (E2E) Testing, User Acceptance Testing (UAT),  Exploratory Testing, UI/UX Testing, Responsive and Cross-Browser Testing, Test Scenario and Test Case Design, Requirements Analysis, Defect Reporting and Tracking, Risk-Based Testing  
### 🔌API Testing  
- REST API Testing, HTTP Methods and Status Codes, Request and Response Validation, Headers, Parameters, and Payload Validation, Positive and Negative Testing, Authentication and Authorization Testing, API Error Handling and Input Validation, API Documentation and Contract Validation  
### 📈 Performance Testing  
- Load Testing Fundamentals, Response Time and Throughput Analysis, Concurrent User Simulation, Basic Performance Test Analysis using JMeter  
### 🤖 Test Automation  
- Playwright, TypeScript, JavaScript Fundamentals, Page Object Model (POM), Reusable Test Helpers, UI and API Test Automation, API-Assisted Test Setup, Assertions and Test Organization, GitHub Actions and CI Fundamentals, HTML Test Reports
